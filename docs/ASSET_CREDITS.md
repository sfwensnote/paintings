# 视觉素材与来源

## 展示输出规则

- 所有画作在结果页使用固定尺寸画框；图片按原比例完整放入画框（`object-fit: contain`），不拉伸、不裁掉画布边缘。不同宽高比的画作会留出不同留白，但外框保持统一。
- 本地展示图统一使用 WebP，最长边不超过 2200 px；清明上河图长卷单独保留 3800 px 宽的横向长卷模式。点击长卷可在新标签页查看完整画面。
- T01–T06 的原始 JPEG 保留不动；页面与结果卡使用对应 `.webp` 展示版。
- T10、T18、T22 尚未取得可用图像授权，结果仍显示作品名牌。T01–T06 为用户提供素材，原始拍摄/数字图像来源和商业发布许可仍待核实。
