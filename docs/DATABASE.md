# 数据库

`database/schema.sql` 在首次启动时创建 SQLite 表。

## 主表

- `sessions`：匿名 `user_id`、`session_id`、答案 JSON、原始/标准化得分、T 编号、Top 1/Top 2–3、相似度、耗时、评分、自由反馈、分享事件、创建/更新时间和全部题库/算法/内容版本。
- `answers`：每题一行，保留 `question_id`、`answer_option`、`raw_score`，会话重新作答时更新原行。
- `artworks`：锚点作品、五维向量、结果叙事、图片 URL、来源、版权、类型编码、人工复核状态与草稿/有效状态。
- `question_set_versions`：按版本保存完整题目与选项计分快照。
- `artwork_set_versions`：按发布版本保存完整有效作品快照。
- `events`：首页、答题、返回、章节完成、测试完成、结果查看、评分和分享等埋点。
- `payment_events`：为后续商业化预留事件记录结构；V1 不开放收款。

## 重算与复现

每个会话创建时记录当前作品集版本。完成时按该快照计算 Top 3。题目配置也按版本查快照。之后编辑并发布的内容不会改变已完成会话的作品文案、作品向量或分享卡片。

原始答案还会同步保存为会话 JSON，便于整次答案导出。维度 raw score 和标准化 score 同存于 `sessions.scores_json`。

## 数据保留

当前无登录用户的删除页面或自动清理任务。SQLite 文件仅在本地持久化。公开部署前需加隐私告知、访问控制、备份与数据保留策略；`user_id` 由客户端生成，不包含姓名、邮箱或微信标识。
